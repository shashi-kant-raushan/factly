## Featured Project

### Factly 🛡️
A misinformation detection system comparing classical ML and transformer-based models for fake vs real news classification.

- TF-IDF + Logistic Regression
- TF-IDF + Random Forest
- Fine-tuned DistilBERT
- Model interpretability using SHAP and feature importance
- Streamlit dashboard for real-time prediction and analysis
